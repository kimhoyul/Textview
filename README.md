# 호율 시리즈

iPhone에서 TXT를 기기에 저장해 오프라인으로 읽는 개인 PWA 텍스트 뷰어입니다.

GitHub Pages 활성화 후 접속 주소: https://kimhoyul.github.io/Textview/

## GitHub Pages 최초 활성화

설정 바로가기: https://github.com/kimhoyul/Textview/settings/pages

1. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
2. **Branch**를 **main**, 폴더를 **/(root)**로 선택합니다.
3. **Save**를 누릅니다.

별도 빌드 없이 루트의 `index.html`을 배포합니다. `.nojekyll`이 포함되어 있으므로 Jekyll 처리는 필요하지 않습니다. 사이트 공개 설정 전에는 위 접속 주소가 열리지 않을 수 있습니다.

## iPhone 사용

Safari에서 사이트 접속 → 공유 → 홈 화면에 추가 → 홈 화면의 호율 시리즈 실행 → 앱 저장 완료 확인 → TXT 가져오기.

인터넷이 연결되어 있을 때 홈 화면 앱에서 앱 저장 및 TXT 가져오기를 완료한 뒤, 비행기 모드와 Wi-Fi 꺼짐 상태에서 앱을 다시 실행해 본문과 다음 화가 열리는지 확인하세요.

소설 TXT와 책장 백업은 GitHub에 업로드하지 마세요. 이 저장소에는 뷰어 프로그램만 포함합니다.

기기 저장 공간 정리나 웹사이트 데이터 삭제에 대비해 원본 TXT 또는 책장 백업을 별도로 보관하세요.

## 회차 제목과 NAS 파일 이름

온라인에서 확인한 회차 제목은 앱에 저장합니다. NAS에 로그인되어 있고 원본 작품 폴더가 연결되어 있으면, 해당 폴더의 숫자 TXT 파일도 `383화 검은 봉인 (3).txt` 형식으로 자동 변경합니다. 연결이 끊겨 있으면 다음 NAS 로그인 때 반영합니다.

NAS에서 새로 가져오는 작품은 원본 폴더를 함께 기록합니다. 이전 버전에서 가져온 작품은 NAS에서 같은 이름의 작품 폴더를 한 번 열면 연결됩니다. 폴더 이름과 작품 정보가 일치할 때만 연결합니다. 이 연결 정보는 이 기기에만 저장하며 책장 백업에는 포함하지 않습니다.

서버는 로그인과 파일 권한을 확인하고 네이버 시리즈의 공개 목차를 다시 대조합니다. 확인한 회차 페이지에 있는 숫자 TXT만 변경합니다. 이름이 이미 있는 파일, 중복 회차, 직접 제목을 붙인 파일은 유지합니다. 본문은 변경하지 않습니다. 파일 이름에 쓸 수 없는 기호는 전각 기호로 바꿉니다.

이름이 바뀐 파일을 다시 가져올 때는 같은 회차의 본문을 비교합니다. 내용이 같으면 기존 책과 읽기 위치를 유지합니다. NAS 연결 서버에는 `episode-rename.php`를 포함한 업데이트가 필요합니다.

## NAS 작품 표지

관리자 화면에서 저장한 표지는 NAS의 해당 작품 폴더에 보관합니다. NAS 로그인 후에는 이미 기기에 있는 작품의 표지도 자동으로 확인합니다. TXT를 다시 가져올 필요가 없습니다. 앱을 다시 열거나 홈과 보관함으로 돌아올 때 확인하며, 앱이 열린 동안에는 5분마다 변경 여부를 확인합니다. 같은 표지는 이미지 전송을 생략합니다.

원본 폴더 정보가 없는 이전 작품은 `/Books/Novel/Completed`와 `/Books/Novel/Ongoing`에서 제목이 같은 폴더 하나를 찾았을 때 표지를 연결합니다. 같은 제목의 폴더가 여러 개면 자동으로 선택하지 않습니다. 이 표지 연결은 NAS의 TXT 파일 이름을 변경하는 원본 연결과 별개입니다.

NAS에서 새 TXT를 가져올 때도 표지를 함께 저장합니다. 인터넷 연결을 끊어도 기기에 저장한 표지를 볼 수 있습니다.

아이폰에서 직접 선택한 표지는 유지합니다. NAS에서 가져온 표지는 같은 원본 폴더의 새 표지로 갱신할 수 있습니다. 표지를 가져오지 못해도 TXT와 읽던 위치는 유지합니다.

표지 메타데이터는 `.hoyul-cover.json`, 이미지는 `.hoyul-cover-<이미지 해시>.jpg`에 저장합니다. 원본 TXT는 변경하지 않습니다. 앱의 표지 조회는 NAS 로그인과 해당 폴더의 읽기 권한을 확인합니다. NAS 연결 서버에는 `shared-cover.php`를 포함한 업데이트가 필요합니다.

## COMIX

상단 COMIX 탭에서 JPG·JPEG·PNG 만화를 읽습니다. NOVEL 책장과 만화 보관함은 별도 저장소를 사용합니다.

보관함의 추가 버튼에서 NAS 또는 이미지 파일을 선택합니다. NAS에서는 작품 폴더를 열고 **이 작품 전체 가져오기**를 누릅니다. 안쪽의 권별 폴더와 중첩 폴더를 찾아 같은 작품으로 묶습니다. 이미지가 있는 폴더마다 한 권으로 저장하며, 선택한 작품 폴더에 직접 들어 있는 이미지도 한 권으로 포함합니다. 빈 폴더와 숨김·시스템 파일은 제외합니다. 권과 페이지는 파일 이름의 숫자순으로 정렬합니다.

가져오기 전에 작품 이름과 전체 권 목록을 확인합니다. 기존 권은 원본 폴더 경로를 유지하므로 다시 가져와도 중복으로 추가되거나 읽던 페이지가 초기화되지 않습니다. 가져오기를 중단하면 완료한 권은 유지합니다. 같은 창에서 다시 시작하면 남은 권부터 이어서 받습니다. 현재 폴더의 이미지만 한 권으로 가져오는 기능도 유지합니다.

만화 이미지는 기기의 COMIX 전용 IndexedDB에 원본 Blob으로 저장합니다. 다운로드를 완료하면 인터넷 없이 읽을 수 있습니다. TXT 책장 데이터와 NAS 원본 파일은 변경하지 않습니다. 만화 보관함의 작품 상세에서 기기에 저장한 작품과 읽던 위치를 삭제할 수 있습니다.

뷰어는 페이지 보기, 세로 스크롤, 왼쪽·오른쪽 읽기 방향, 페이지 슬라이더와 권 간 이동을 지원합니다. 본문을 두 번 탭하면 상단·하단 메뉴를 표시하거나 숨깁니다. 읽던 권과 페이지를 자동으로 저장합니다.

NAS 연결 서버에는 이 버전의 `api.php`와 `synology.php`를 함께 적용해야 합니다. 기존 설정 파일은 유지합니다. 만화 다운로드도 로그인·CSRF·세션 만료·DSM 읽기 권한을 검사합니다. 이미지 한 장은 32MB까지 지원합니다.
