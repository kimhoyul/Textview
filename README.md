# Textview

iPhone에서 TXT를 기기에 저장해 오프라인으로 읽는 개인 PWA 텍스트 뷰어입니다.

GitHub Pages 활성화 후 접속 주소: https://kimhoyul.github.io/Textview/

## iPhone 사용

Safari에서 사이트 접속 → 공유 → 홈 화면에 추가 → 홈 화면의 TXT 책장 실행 → 앱 저장 완료 확인 → TXT 가져오기.

소설 TXT와 책장 백업은 GitHub에 업로드하지 마세요. 이 저장소에는 뷰어 프로그램만 포함합니다.

기기 저장 공간 정리나 웹사이트 데이터 삭제에 대비해 원본 TXT 또는 책장 백업을 별도로 보관하세요.
