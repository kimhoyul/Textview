# 호율 시리즈 — 공개 웹앱

이 저장소에는 호율 시리즈의 **웹앱 배포 파일만** 포함합니다.

- NOVEL: TXT 보관함, 읽기, 편집, 읽기 위치·책갈피
- COMIX: 만화 이미지 보관함과 오프라인 읽기
- NAS 연결: 브라우저에서 실행되는 **클라이언트 JavaScript만** 포함

NAS의 인증·파일 처리 서버 코드(PHP), 서버 설정과 자격 증명은 공개 저장소에 넣지 않습니다. 웹 브라우저에 전달되는 클라이언트 파일에는 NAS 접속 주소가 보일 수 있으며, 인증과 파일 접근 권한 검증은 NAS 서버가 담당해야 합니다.

## 작품 관리 상단 디자인 개선 (v2.17.2)

**작품 관리 → 목차·순서** 화면의 상단을 레퍼런스에 맞게 수정했습니다. 작품명과 TXT 개수를 보라색 그라데이션 제목 카드로 묶고, 검색창에 돋보기 아이콘을 배치했습니다. 순서 이동 안내에는 정보 아이콘을, 회차 번호순 복원 버튼에는 복원 아이콘과 기존 키컬러를 적용했습니다. 아래 회차 목록 및 드래그·이름 수정·위치 이동·삭제 기능, TXT/IndexedDB 데이터와 NAS 서버 코드는 변경하지 않았습니다.

## 목차 순서 손잡이 개선 (v2.17.1)

**작품 관리 → 목차·순서**의 기존 큰 보라색 사각형 손잡이를 배경 없는 회색 6점 드래그 아이콘으로 변경했습니다. 회차 위치 번호도 회색 보조 텍스트로 조정했습니다. 시각적인 아이콘은 작게 유지하지만 드래그 터치 영역(42×44px)은 유지하며, 드래그 저장·이름 수정·위치 이동·삭제·검색과 PWA 데이터는 변경하지 않습니다.

## 회차 관리 메뉴 및 안전한 TXT 삭제 (v2.17.0)

NOVEL → 작품 관리 → **목차·순서**에서 각 회차 행을 **왼쪽 드래그 손잡이 / 가운데 제목·파일명 / 오른쪽 ⋮ 메뉴**로 간결하게 변경했습니다. ⋮을 누르면 **이름 수정, 위치 이동, 삭제** 세 기능을 선택할 수 있습니다. 터치 드래그와 회차 번호순 복원·검색·100개씩 더 보기는 유지됩니다.

**삭제**는 회차 파일명과 편집 본문·읽기 위치·책갈피가 삭제됨을 명시하는 확인창을 거쳐야 실행됩니다. 마지막 회차라면 책도 보관함에서 사라진다는 추가 경고가 표시됩니다. 삭제는 사용자의 기기 IndexedDB에서만 수행되며, NAS 및 iOS 파일 앱의 원본 파일은 삭제하지 않습니다. 다른 책 및 남은 회차·읽기 기록·표지는 그대로 유지됩니다. 저장 실패나 다른 창의 목록 변경은 삭제하지 않고 오류를 표시합니다.

## 원본 TXT 파일명 편집 및 드래그 회차 이동 (v2.16.0)

**작품 관리 → 목차·순서**에서 회차별 **이름 수정**을 누르면 앱에 저장된 실제 TXT 파일명을 수정합니다. 확장자 `.txt`는 자동으로 붙습니다. 내부 회차 ID와 본문·책갈피·읽던 위치·지정 순서는 하나의 저장 트랜잭션에서 변경해 데이터가 끊기지 않도록 보호합니다. 중복 파일명과 잘못된 파일명은 거부합니다.

회차별 **⠿ 손잡이**를 아이폰에서 손가락으로 끌어 원하는 행 위·아래에 놓으면 순서가 변경됩니다. 기존 **위치 이동** 번호 입력도 유지합니다. 검색 결과만 표시 중일 때는 혼동을 막기 위해 드래그를 비활성화합니다.

실제 파일명 변경 대상은 **PWA 보관함(IndexedDB)에 저장된 TXT**입니다. iOS 파일 앱에서 원래 선택했던 파일과 NAS 서버의 원본은 변경하지 않습니다. 기존 NAS 이름이 남아 있으면 중복 업로드하지 않도록 보호하며, 앱의 백업에는 수정한 파일명을 포함합니다.

## 작품 관리 통합 (v2.15.0)

NOVEL 보관함에서 작품을 선택하면 기존 **표지 선택** 대신 **작품 관리** 화면이 열립니다. **표지 설정**과 **목차·순서**를 탭으로 전환할 수 있습니다. **보관함 → 편집 → 해당 작품의 작품 관리** 또는 **작품 상세 → 순서 편집**은 목차 탭을 직접 엽니다.

목차 탭에서 TXT를 검색하고 **위치 이동**을 눌러 원하는 위치 번호를 지정하면 순서를 즉시 저장합니다. **회차 번호순 복원**으로 수동 지정을 해제할 수 있습니다. 큰 책은 처음 100개를 표시하며 더 보기로 계속 탐색할 수 있습니다.

표지 검색·이미지 직접 선택·기본 표지 기능은 유지하며 표지 저장 후에도 작품 관리 화면에 머무릅니다. 같은 화면에서 새 TXT, TXT 가져오기, 책 이름 변경으로 이동할 수 있습니다. 기존 IndexedDB의 TXT 본문·읽기 기록·순서 데이터와 NAS 서버 코드는 바꾸지 않습니다.

## 회차 번호순·사용자 순서 편집 (v2.14.0)

`1화.txt`를 `20화.txt`·`21화.txt`보다 나중에 추가해도 **1화 → 20화 → 21화** 순서로 정렬합니다. `1화_프롤로그.txt`처럼 회차 번호로 시작하는 이름도 인식합니다. 번호가 없는 TXT는 추가 위치를 근거로 임의의 화수를 붙이지 않습니다.

**작품 상세 → 순서 편집**, 또는 **목차·내 책장 → 순서 편집**에서 TXT의 위치 이동을 누르고 원하는 위치 번호를 지정할 수 있습니다. 필요하면 **회차 번호순 복원**을 눌러 사용자 지정을 초기화합니다. 지정한 순서는 기기에 저장되고 백업·복원에서도 유지됩니다. 읽던 위치, 책갈피, 편집 본문, NAS 원본은 변경하지 않습니다.

## NAS·노벨피아 표지 검색 연결 상태

검색 결과가 없다는 메시지와 NAS 서버가 검색 기능을 제공하지 못하는 문제를 구분합니다. 상태 조회 `health=1` 실패 시 HTTP 오류·연결 불가·PHP cURL 비활성화·검색 서버 기능 비활성화 등을 표시합니다.

NAS 서버의 `cover-search.php`는 비공개 원본에서 별도로 관리됩니다. 노벨피아 작품명·표지 검색은 PHP DOM이 없더라도 cURL만 있으면 실행되도록 수정했습니다. 네이버 시리즈의 HTML 검색은 DOM 확장이 필요합니다.

## 직접 새 책·새 TXT 작성

**NOVEL → 보관함 → + → 새 TXT 만들기**에서 책 이름, TXT 이름, 본문을 입력하고 저장합니다. 기존 책 이름을 선택하면 그 책의 회차로 추가되고, 새 책 이름이면 새 작품이 생성됩니다. 빈 본문도 저장할 수 있으며 `.txt` 확장자는 자동으로 붙습니다.

기존 작품에 추가할 때는 **보관함 → 편집 → 해당 작품의 새 TXT** 또는 **목차·내 책장 → 새 TXT 만들기**를 이용할 수 있습니다. 다른 파일을 덮어쓰지 않고 사용자가 작성한 본문을 기존 IndexedDB에 저장하므로 오프라인 읽기·본문 편집·백업에 포함됩니다. NAS 서버 파일이나 기존 NAS 폴더를 변경하지 않습니다.

## 네이버 시리즈 회차 메타데이터

일부 작품은 연재본 이름에 `[외전 독점]`을 붙이지만 본편과 외전을 모두 수록합니다. 회차 조회에서만 이 정확한 표기를 별칭으로 취급하고 `[단행본]`과 혼동하지 않습니다.

공식 회차 목록에 별도 제목 없이 `1`, `1화` 등 번호만 있으면 실제 소제목으로 저장하지 않습니다. 기존 오프라인 책의 이름, TXT 본문, 편집본, 파일명, 읽기 위치는 변경하지 않으며, 회차는 `1화`처럼 중복 숫자 없이 표시합니다. 별도 소제목이 있는 회차만 제목을 적용합니다.

## 배포

GitHub Pages에서 `main` 브랜치의 `/(root)`를 배포합니다.

**기존 앱 주소:** https://kimhoyul.github.io/Textview/

기존 사용자의 로컬 TXT·편집 본문·읽기 기록을 사용하려면 프로토콜·호스트·경로를 그대로 유지해야 합니다. 앱 본문과 기록은 사용자의 IndexedDB에 보관되며 GitHub에 업로드되지 않습니다.

## 공개 코드 관리

`nas-gateway/`, PHP·SQL, 서버 설정, 개인 API 키, 자격 증명, 환경 변수 파일을 공개 저장소에 추가하지 않습니다. 별도의 비공개 원본 저장소에서 서버 코드를 관리합니다.

이 배포 저장소는 **오래된 전체 소스 Git 기록을 복제하지 않고** 안전한 초기 기록과 최신 정적 웹 자산만 사용합니다.
