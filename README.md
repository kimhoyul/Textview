# 호율 시리즈 — 공개 웹앱

이 저장소에는 호율 시리즈의 **웹앱 배포 파일만** 포함합니다.

- NOVEL: TXT 보관함, 읽기, 편집, 읽기 위치·책갈피
- COMIX: 만화 이미지 보관함과 오프라인 읽기
- NAS 연결: 브라우저에서 실행되는 **클라이언트 JavaScript만** 포함

NAS의 인증·파일 처리 서버 코드(PHP), 서버 설정과 자격 증명은 공개 저장소에 넣지 않습니다. 웹 브라우저에 전달되는 클라이언트 파일에는 NAS 접속 주소가 보일 수 있으며, 인증과 파일 접근 권한 검증은 NAS 서버가 담당해야 합니다.

## 네이버 시리즈 회차 메타데이터

일부 작품은 연재본 이름에 `[외전 독점]`을 붙이지만 본편과 외전을 모두 수록합니다. 회차 조회에서만 이 정확한 표기를 별칭으로 취급하고 `[단행본]`과 혼동하지 않습니다.

공식 회차 목록에 별도 제목 없이 `1`, `1화` 등 번호만 있으면 실제 소제목으로 저장하지 않습니다. 기존 오프라인 책의 이름, TXT 본문, 편집본, 파일명, 읽기 위치는 변경하지 않으며, 회차는 `1화`처럼 중복 숫자 없이 표시합니다. 별도 소제목이 있는 회차만 제목을 적용합니다.

## 배포

GitHub Pages에서 `main` 브랜치의 `/(root)`를 배포합니다.

**기존 앱 주소:** https://kimhoyul.github.io/Textview/

기존 사용자의 로컬 TXT·편집 본문·읽기 기록을 사용하려면 프로토콜·호스트·경로를 그대로 유지해야 합니다. 앱 본문과 기록은 사용자의 IndexedDB에 보관되며 GitHub에 업로드되지 않습니다.

## 공개 코드 관리

`nas-gateway/`, PHP·SQL, 서버 설정, 개인 API 키, 자격 증명, 환경 변수 파일을 공개 저장소에 추가하지 않습니다. 별도의 비공개 원본 저장소에서 서버 코드를 관리합니다.

이 배포 저장소는 **오래된 전체 소스 Git 기록을 복제하지 않고** 안전한 초기 기록과 최신 정적 웹 자산만 사용합니다.
