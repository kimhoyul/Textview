오프라인으로 사용하기

      
인터넷이 연결된 상태에서 Safari의 공유 → 홈 화면에 추가를 선택하세요. ‘웹 앱으로 열기’가 보이면 켜 주세요.

      
홈 화면의 ‘TXT 책장’을 다시 열고, ‘앱 저장 완료’ 표시를 확인한 뒤 TXT를 가져오세요. 비행기 모드에서 앱을 닫았다가 다시 열어 본문이 나오는지 확인하면 됩니다.

      
다운로드한 HTML을 파일 앱에서 직접 여는 방식은 오프라인 설치가 아닙니다. 처음 설치에는 HTTPS 웹 주소가 필요합니다. Safari와 홈 화면 앱의 책장이 같다고 가정하지 말고, 사용할 앱 안에서 TXT를 추가하세요.
